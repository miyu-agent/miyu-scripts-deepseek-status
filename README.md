# DeepSeek service status

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

This is a script package for Miyu. It provides one tool, `deepseek_status`. It reads the official DeepSeek status page <https://status.deepseek.com/> and returns the current state and 30-day uptime of each service (the API models, chat, search, file upload and so on), the incidents being handled (which services are affected, the latest update), and the most recent incidents.

| Parameter | Description |
|---|---|
| `incidents` | How many recent incidents to list, 0–20, default 3; 0 lists none |
| `format` | `md` (default) is for people and the AI to read; `json` is for code, for example `miyu call` piped into `jq` or Python. Errors are returned as JSON too: `{"ok": false, "error": …}` |

The list of services follows whatever the status page currently shows; it is not hard-coded in the script. Times are in Beijing time. The tool uses only the standard library. The status page is a Next.js page, and the data is read from the `self.__next_f.push` fragments in it; if the page is redesigned and the data can no longer be read, the tool says so clearly and asks the user to open the status page themselves.
